The question

More capacity in a running plant

Abbott wanted more production capacity in Zwolle. Each new line had to be delivered turnkey and had to start up fast, in a plant that keeps producing.

What we built
  • Lines up to 30,000 bottles per hour, for bottles from 125 ml to 1,500 ml
  • Unloading dock, depalletisers and air cleaners
  • Inliners, buffers and all conveyors for bottles, packs, trays and pallets
  • Robot palletisers
  • Line integration, line control and SCADA
  • Every line built and tested in Dongen first
